HUDDLE — APPROVED ASSETS + EXPO DESIGN SYSTEM

This package contains the approved Huddle visual assets and the Soft Minimal design system for BOTH Expo applications:

1. Phone controller app (iOS + Android)
2. TV shared-stage app

The apps share brand tokens and visual language, but phone and TV use different presentation scales and interaction rules.

No NativeWind/Tailwind dependency is included.
