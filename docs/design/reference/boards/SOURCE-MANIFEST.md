# Huddle approved reference boards

These images are the approved visual inputs for the current Expo Phone and TV
surfaces. They support comparison and provenance; the active visual rules live
in [`../../soft-minimal-handoff.md`](../../soft-minimal-handoff.md).

## Phone app

1. [`01-join-room.png`](../screens/01-join-room.png) — Join layout and styling reference.
2. [`02-your-room-host.png`](../screens/02-your-room-host.png) — Host room layout reference.
3. [`03-manage-player-host.png`](../screens/03-manage-player-host.png) — player-management sheet reference.
4. [`04-pick-a-game-host.png`](../screens/04-pick-a-game-host.png) — game-picker reference.
5. [`05-waiting-player.png`](../screens/05-waiting-player.png) — waiting-player reference.
6. [`06-game-settings-host-standard.png`](../screens/06-game-settings-host-standard.png) — Host game-settings state with the Standard preset.
7. [`07-game-settings-host-quick.png`](../screens/07-game-settings-host-quick.png) — Host game-settings state with the Quick preset.
8. [`08-game-settings-host-custom.png`](../screens/08-game-settings-host-custom.png) — Host game-settings state with custom options.
9. [`09-game-finished-player.png`](../screens/09-game-finished-player.png) — player post-game layout provenance.
10. [`10-game-finished-host.png`](../screens/10-game-finished-host.png) — Host post-game layout provenance.

The post-game images are layout provenance only; the current milestone has no
results phase. The board also predates Ready and module-owned entered screens,
which follow the active handoff instead.

## TV app

1. [`01-room.png`](../screens/01-room.png) — Room reference. It depicts 12 seats; the current product cap is 10.
2. [`02-game-carousel.png`](../screens/02-game-carousel.png) — Game carousel.
3. [`03-game-setup.png`](../screens/03-game-setup.png) — Trivia setup state while the Host prepares the game.

The reference set has no TV Ready state or game-specific entered screens. The
room and carousel files are content-only 1672×941 (16:9) exports that align with
the runtime TV backgrounds; they intentionally omit a television bezel.
