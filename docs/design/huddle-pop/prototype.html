Motion

  • Hop-in750 ms spring. A player lands on the couch with a squash.
  • Glide600 ms spring. Cards slide and tilt to where the host’s swipe lands.
  • Flash1.3 s. A setting the host just changed pops yellow on the TV.
  • Tick1 s per number. The ring drains while the crew bounces on each beat.
  • Wipe800 ms circle in the game’s colour, then the game takes over.
  • IdleBlobs breathe and blink, doodles drift. Slow, so nothing distracts.

Building it in React Native

  • Shapes map to react-native-svg, which the TV already uses. The phone would add it.
  • Hops, glides, flashes, the wipe and the countdown are transform and opacity animations. RN’s built-in Animated API can drive those natively.
  • The blob wobble morphs SVG paths. That needs Reanimated, which the architecture checks currently forbid. Otherwise we keep a transform-only squash-and-bob, which looks about 90% the same.
  • Reduced motion: blobs sit still and transitions are instant. Numbers and copy still change.
